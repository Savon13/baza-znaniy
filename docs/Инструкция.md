# 📖 Инструкция

## Как загрузить новый материал

1. Зайдите на github.com/Savon13/baza-znaniy (нужен вход в аккаунт).
2. Откройте нужную папку:
   - `docs/Лекции/` — для лекций
   - `docs/Домашние задания/` — для дз
   - `docs/Полезное/` — для всего остального
3. Нажмите **Add file** → **Upload files**.
4. Перетащите файл (PDF, DOCX, PPTX) в окно браузера.
5. В поле «Commit changes» напишите короткое описание, например: «Лекция по КП 15.10».
6. Нажмите зелёную кнопку **Commit changes**.

Через 1–2 минуты файл появится на сайте: savon13.github.io/baza-znaniy

## Как добавить объявление

1. Откройте файл `docs/index.md`.
2. Нажмите карандаш ✏️.
3. Добавьте вверху строку вида:
   `> 📢 **Внимание:** завтра сдаём зачёт!`
4. Commit changes.
